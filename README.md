# TachoControl

Driver Hours & Rest — aplicação PWA em desenvolvimento para acompanhamento manual de jornada, condução, outros trabalhos, disponibilidade, cama/pausa, repousos e relatórios.

Versão publicada inicialmente: v1.13.4.

Este projeto ainda está em fase de testes e não substitui o tacógrafo nem validação jurídica profissional.
